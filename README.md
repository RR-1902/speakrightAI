# SpeakRightAI 🎤

> Real-time AI pronunciation coach with phoneme-level feedback and scoring.

---

## 🌟 Features

* 🎤 Live microphone recording + audio upload
* 🧠 Phoneme-level pronunciation analysis (CMUdict)
* 📊 AI-based pronunciation scoring system
* 📈 Session-based progress tracking
* ⚡ Whisper-powered speech-to-text
* 🎨 Modern glassmorphism UI (React + Tailwind)

---

## 🚀 Key Highlights

* Real-time microphone-based pronunciation analysis
* Phoneme-aware scoring (not just text matching)
* Session-based learning system with progress tracking
* Fully dockerized for one-command execution

---

## 🧠 How It Works

Speech Input → Whisper Transcription → Phoneme Extraction → Comparison → Score + Feedback

---

## 🧩 Architecture

Frontend (React) → FastAPI Backend → Whisper + Phoneme Engine → Scoring System
